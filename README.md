# Basketball League & Season Simulator (OOP)

A Python-based simulation engine for a multi-week basketball tournament featuring EuroLeague teams, managers, and players.

## Core Features
* **Object-Oriented Architecture:** Implements class inheritance (`Person` -> `Player`, `Manager`), encapsulation, and composition (`Team`, `Match`, `Season`).
* **Operator Overloading:** Custom comparison logic (`__lt__`) for standings ranking and tie-breakers.
* **Match Simulation:** Deterministic and stochastic score calculations taking into account shooting attributes, manager influence factors, and overtime rules.
* **Fixture Generation:** Round-robin scheduling algorithm for multi-week tournaments.

## Technologies
* Python 3
* Object-Oriented Programming (OOP)
